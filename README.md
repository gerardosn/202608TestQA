# PodScript UI — Scaffold

Esta rama contiene un scaffold inicial para la UI en React + TypeScript + Vite + Tailwind.

Instrucciones rápidas:

1. Instala dependencias:

```bash
npm install
```

2. Ejecuta en modo desarrollo:

```bash
npm run dev
```

Notas:
- Tailwind ya está configurado en tailwind.config.cjs
- La rama donde se agregó el scaffold es `feature/ui/react-screens`
- Próximo paso recomendado: implementar componentes UI y pantallas dentro de `src/ui/`.
